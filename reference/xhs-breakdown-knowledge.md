## 1. 低粉爆款判定标准

「低粉爆款」= 粉丝量不高，但单条内容互动远超其粉丝量级。特征：
- 粉丝 < 5000，但赞藏评合计明显高于同粉丝量级账号
- 收藏比（藏/赞）高 → 内容「有用、可复用」，用户愿意存
- 评论数高 → 引发讨论/共鸣/争议，具备传播性
- 通常不是靠颜值/剧情，而是靠**信息差、情绪共鸣、方法干货**

## 2. 爆款指数口径（与脚本一致）

```
爆款指数   = (赞 + 藏×1.5 + 评×3) / max(粉丝, 100)
收藏比     = 藏 / max(赞, 1)
互动加权分 = 赞 + 藏×1.5 + 评×3        # 缺粉丝数时的账号内横向比较口径
```

- 评论权重最高（×3）：代表讨论与二次传播
- 收藏权重次之（×1.5）：代表内容价值与复用意愿
- 分母用 `max(粉丝,100)`：避免零粉丝账号虚高，也防止大 V 被过度压低
- 标签规则：粉丝<5000 且指数>0.5 → 低粉爆款；收藏比≥1 → 高收藏；评论≥50 → 高互动

## 3. 开头钩子库

| 钩子类型 | 机制 | 示例 |
|---|---|---|
| 悬念反差 | 打破预期，制造好奇 | "我劝你别轻易试这个方法" |
| 痛点直击 | 一句话戳中目标人群困境 | "做了3个月小红书0爆款，问题在这" |
| 数字具象 | 用具体数字建立可信度 | "30天涨粉5000，只做了1件事" |
| 身份认同 | 让用户对号入座 | "普通女生怎么靠副业多赚3000" |
| 情绪共鸣 | 引发共情或爽感 | "终于有人把这件事说清楚了" |
| 结果前置 | 先给甜头再讲方法 | "收藏这个模板，选题不用愁了" |
| 动作特写 | 视频前3秒直接展示"正在做" | 胶枪点胶、手在组装（无需台词） |

## 4. 内容结构模型

- **AIDA**：注意(Attention)→兴趣(Interest)→欲望(Desire)→行动(Action)。适合种草/转化类。
- **PAS**：问题(Problem)→放大(Agitate)→解决(Solution)。适合痛点干货类。
- **故事弧**：背景→冲突→转折→结局→感悟。适合个人经历/IP 类。
- **清单式**：1/2/3 分点罗列，易读易藏。适合方法/资源类。
- **对比式**：Before/After 或 A vs B。适合测评/避坑类。
- **教程式**：目标→准备→步骤→结果。适合实操教学类。

> 拆解时先判定主模型，再补「情绪/节奏设计」（哪里制造期待、哪里给确定性、哪里引导互动）。

## 5. 标题公式库（11 种）

| 公式 | 模板 | 示例 |
|---|---|---|
| 数字+痛点+结果 | 「N个{方法}，搞定{痛点}」 | "5个选题模板，搞定没灵感" |
| 身份+反差+方法 | 「{身份}也能{结果}」 | "上班族也能月入过万" |
| 避坑+数字 | 「别再{错误}了，{N}个坑」 | "别再乱发笔记了，3个坑" |
| 结果前置+钩子 | 「{成果}，只因{1件事}」 | "爆款不断，只因选对赛道" |
| 提问+承诺 | 「{痛点}？{承诺}」 | "没流量？这份清单救你" |
| 亲测型 | 「亲测{N}天，{结果}」 | "亲测21天，账号起量了" |
| 感叹型 | 「{情绪词}！{发现}」 | "天呐！松果还能这么玩" |
| 疑问型 | 「{现象}，为什么？」 | "她为什么6天涨粉712？" |
| 降门槛型 | 「0基础也能{结果}」 | "0成本手工，新手也能做" |
| 发现型 | 「我发现了个宝藏{对象}」 | "我发现了个宝藏挂件玩法" |
| 热点词型 | 「{热点词}爆了，{场景}」 | "森系爆了，我家松果有救了" |

标题要点：前 13 字决定点击（信息流只露前半句）；善用 emoji 分隔；关键词前置；避免标题党过度（影响权重）。

## 6. 小红书风格要点

- **口语化**：像朋友安利，不端着；多用「我/你/咱们」
- **分段留白**：短句、空行、emoji 小标题，手机阅读友好
- **价值密度**：前 3 行给结论或钩子，别铺垫太久
- **互动引导**：结尾抛问题 / 求收藏 / 引导关注
- **封面逻辑**：标题即封面文案，字少而准，3 秒内懂

## 7. 评论区分析方法

- 提取**高赞评论**主题 → 用户最关心的点
- 提取**追问/求资源**评论 → 内容空白与延伸机会（如"配件哪里买"= 材料包需求）
- 提取**反对/补充**评论 → 可差异化的角度
- 评论区情绪走向 = 内容共鸣度的真实信号
- 提炼**"下一步内容机会"**：用户还想知道什么、还缺什么

## 8. 人设三板斧（粉丝为什么跟 TA）

拆解一个账号时，回答这三个问题，就是"人设三板斧"：
1. **TA 是谁**（身份/职业/生活状态）→ 用户为什么信 TA
2. **TA 解决了什么**（具体痛点/情绪/审美）→ 用户为什么需要 TA
3. **TA 的差异化记忆点**（视觉符号/口头禅/固定动作）→ 用户为什么记住 TA

## 9. 藏赞比三档分析

把账号全量笔记按「收藏比 = 藏/赞」分三档，判断账号调性：
- **实用型（藏/赞 ≥ 1）**：教程/干货/清单，用户当工具书存 → 高转化潜力
- **均衡型（0.5–1）**：审美+实用混合，内容有保存价值也有情绪
- **情绪型（< 0.5）**：共鸣/颜值/剧情，看完即走，不易沉淀

> 对标账号若以实用型为主，说明赛道偏"方法干货"，适合你做教程号切入。

## 10. 常见赛道高潜特征

| 赛道 | 高潜特征 |
|---|---|
| 职场/副业 | 具体方法、可复制、数字结果 |
| 美妆/穿搭 | 对比实测、避坑、平价替代 |
| 育儿/情感 | 共鸣故事、情绪价值、身份认同 |
| AI工具/效率 | 实操教程、资源合集、降本增效 |
| 手工/DIY/自然物 | 低成本材料+高颜值成品+可复制步骤 |
| 知识/学习 | 清单、模板、体系化框架 |

> 赛道特征仅作拆解参考，最终以「用户自身经历与观点」做差异化才是原创关键。

## 11. 「为什么火 / 怎么验证」判断清单

拆解任何爆款，必须回答归因派四问：

1. **为什么能火**：选题命中什么痛点/情绪/信息差？视觉/标题/结构哪一项拉满？
2. **什么值得学**：可复制的"结构骨架"是什么（开头钩子 + 结构模型 + CTA）？
3. **新号先学什么**：从哪一条最小动作开始模仿（先抄结构，再填自己的内容）？
4. **如何验证打法**：设计一个最小成本测试（如"用同样结构拍 1 条自家版本"），看完播/收藏反馈决定是否放大。

> 行动路线图据此拆成 P0（5 分钟可粘贴执行）/ P1（24 小时互动钩子）/ P2（月度转型方向）。
